# Portfolio Analytics & Risk-Return Optimization System

A Python-based project that analyzes a 15-stock portfolio across multiple sectors,
calculates risk and return metrics, and applies Modern Portfolio Theory to find an
optimal asset allocation.

## Status
🚧 In progress — Weeks 1–2 complete (data pipeline, risk and return metrics).
Portfolio optimization, backtesting, and dashboard coming next.

## What This Project Does
- Pulls historical stock price data for 15 stocks across 5 sectors (Banking, IT, FMCG,
  Auto, Pharma) plus the Nifty 50 benchmark
- Stores and queries the data using SQLite
- Calculates annualized return, volatility, Sharpe ratio, and beta for each stock
- Builds a correlation matrix to understand how stocks move together
- *(Coming next)* Runs a Monte Carlo simulation to find the optimal portfolio
  allocation using Modern Portfolio Theory
- *(Coming next)* Backtests the optimized portfolio against the benchmark
- *(Coming next)* Visualizes results in an interactive Power BI dashboard (planned)

## Tools Used
- Python (pandas, numpy, yfinance, matplotlib, seaborn)
- SQLite (data storage and querying)
- Power BI *(planned)*
